# Bluetooth Speaker 原理图整改说明

由于直接往嘉立创 EDA 原理图里追加文本标注会出现显示乱码，所以原理图文件已经恢复，整改建议单独放在这个文件里。

## 优先整改项

1. USB-C 输入
- F1 可以继续保留在 VBUS 上，建议确认它靠近 USB-C 接口，并位于输入路径前端。
- 建议在 USB-C 的 VBUS 到 GND 之间增加 TVS 管，靠近接口放置。
- USB-C 外壳/屏蔽脚的接地方式需要明确，至少要考虑 ESD 泄放路径。

2. 电池输入
- 如果 BAT 接的是裸锂电池或裸聚合物电池，需要增加电池保护 IC/保护板，具备过充、过放、过流、短路保护。
- 如果使用的是自带保护板的电池，建议在原理图中标注“使用带保护电池”。

3. 3.3V 电源
- 需要核算 3.3V 稳压芯片的峰值电流余量，负载包括 ESP32-S3、TF 卡、OLED、传感器和功放相关电路。
- 建议在 ESP32-S3 模块、TF 卡座、OLED/手势识别/麦克风模块接口附近分别增加 100nF + 10uF 去耦电容。

4. I2C 总线
- 建议在主板上预留 I2C_SCL 和 I2C_SDA 到 +3.3V 的 4.7k 上拉电阻，默认可以做成 DNI/不焊。
- 需要确认 OLED 和手势识别模块板上是否已经自带上拉电阻，避免多个模块并联后等效上拉阻值过小。

5. MAX98357A 功放
- SD_MODE# 需要有明确的默认电平，建议预留 100k 上拉或下拉电阻焊盘，并根据声道/模式配置确认接法。
- 需要按 MAX98357A 官方参考设计重新检查喇叭输出端的 LC/电容网络。很多 MAX98357A 用法是 filterless 直接推喇叭，错误的滤波网络可能导致失真、发热或稳定性问题。

6. ESP32-S3 启动脚
- 需要确认 TF 卡、按键、I2S、I2C 等外设没有接到会影响 ESP32-S3 启动模式的 strapping/download 相关 GPIO。
- 尤其要检查上电瞬间这些外设是否会把启动脚拉到错误电平。

7. TF 卡
- 建议在 TF 卡座电源脚附近增加 100nF + 10uF 去耦电容。
- TF_CLK 走线应尽量短，并保持完整地参考。
- 如果硬件只连接 CMD、CLK、DAT0、CD，需要确认固件使用 1-bit SD 模式。

8. IP5306
- 需要根据 IP5306 手册确认是否支持当前的边充边放/电源路径接法。
- 需要复核 R2 对应的充电电流设置是否合适。
- 需要确认 LED 引脚是否为内部恒流输出；如果不是，需要给 LED 加限流电阻。
