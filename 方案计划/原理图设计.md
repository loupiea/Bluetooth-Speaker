# 蓝牙智能音响 — 原理图设计 (底板 + ESP32-S3 开发板)

## 0. 方案说明

**ESP32 不裸焊**，直接买现成的开发板，底板提供排母插座，开发板插上即可。好处：

- 不用画 ESP32 模块封装和外围（晶振、Flash、天线匹配全在开发板上搞定）
- 烧录直接用开发板自带的 USB-C（内置 USB-Serial-JTAG），底板不用留烧录口
- 原型调试时开发板可拔下来单独测试
- 量产时可以保留插座结构（方便维修），也可以改回模块焊接

### 推荐开发板

| 型号 | 价格 | USB | 引脚 | 优点 |
|------|------|-----|------|------|
| **嘉顺电子科技 ESP-S3 N16R8** | ~35 元 | USB-C | 2×22P 排针 2.54mm | 16MB Flash + 8MB PSRAM, 双排针标准好插 |
| ESP32-S3-DevKitC-1 | ~70 元 | USB-C | 2×19P 排针 2.54mm | 官方板, 最稳定 |
| 合宙 ESP32-S3 | ~25 元 | USB-C | 2×18P 半孔焊盘 | 便宜但需要焊接排针 |

> 选用 **嘉顺电子科技 ESP-S3 N16R8**：2×22P 双排 2.54mm 排针直接插底板排母，拔插方便。N16R8 (16MB Flash + 8MB PSRAM)，所有关键 GPIO 引出，5V/3.3V/GND 都在排针上。

**供电逻辑**：
- 开发板插在底板上时 → 由底板 3.3V_D 供电（开发板 3.3V 引脚有电）
- 开发板拔下单独调试时 → 开发板自己的 USB-C 供电
- 开发板 USB-C 只用于烧录和串口，不对外供电
- 底板 USB-C 只用于充电（→ IP5306），不做数据

## 2. 底板电源电路

### 2.1 总供电树

```
底板 USB-C (仅充电) ──→ PTC+5.6V ──→ IP5306 ──→ 5V BUS
                                       │
                          ┌────────────┴────────────┐
                          ↓                         ↓
                    18650 电池                底板 5V 输出
                    (DW01 保护)                   │
                                    ┌─────────────┼─────────────┐
                                    ↓             ↓             ↓
                              功放 5V_AUDIO   SY8088→3.3V_D  5V 备用
                              (经磁珠 FB1)       │
                                                 │
                                    ┌────────────┴────────────┐
                                    ↓                         ↓
                              数字外设 3.3V_D            INMP441 3.3V_D
                              (开发板+OLED+TF        (数字麦克风, LDO-free)
                               +手势+功放控制)

SY8088 一颗搞定全部 3.3V。全数字音频，无模拟域。
```

### 2.2 底板 USB-C 6P (充电专用)

USB-C 6P 母座仅用于充电，只保留 VBUS、GND、CC1、CC2 四组引脚。比 16P 体积更小、引脚更少，完全够用。

```
USB-C 6P (底板, 仅充电):
  VBUS  → USBLC6-2SC6 → PTC 500mA → 5.6V 稳压管↓ → IP5306 VIN
  GND   → GND
  CC1   → 5.1kΩ → GND  [必须, C-to-C 线识别]
  CC2   → 5.1kΩ → GND  [必须, 支持正反插]
  D+/D- → 不存在 (6P 不引出数据)

注意: 这是底板的 USB-C, 和开发板 USB-C 不是同一个口!
     底板 USB-C → 充电
     开发板 USB-C → 烧录/串口
```

### 2.3 IP5306 充放电

```
与之前方案相同, 仅 EN 控制改为:
  IP5306.KEY(5) → SW_POWER + Q_AO3400.Drain (软关机由底板 GPIO 控制)
  但开发板拔下来后 GPIO 悬空 → 需要确保 N-MOS 默认关断

解决方案:
  Q_AO3400.Gate → 10kΩ 下拉到 GND (默认关断, 开发板 GPIO 高时才导通)
  Q_AO3400.Gate → 开发板 GPIO11 (通过排母连接)

5V BUS 输出到排母:
  J1.Pin2(5Vin) ← 5V BUS (供开发板可选 5V 供电)
```

### 2.4 SY8088 → 3.3V_D

```
5V BUS → C_10μF+C_0.1μF → SY8088.VIN(1)
SY8088.SW(3) → L_3.3μH_CD32 → 3.3V_D
SY8088.FB(4) → GND (固定 3.3V)
SY8088.EN(5) → 直接 3.3V_D (自举)
SY8088.GND(2) → GND

3.3V_D → J1.Pin21(3V3), J1.Pin22(3V3) (开发板供电)
3.3V_D → 所有数字外设
```

## 3. 开发板排母接口

嘉顺电子科技 ESP-S3 N16R8 排针是标准 2.54mm 双排, 每排 22P。底板放两排 1×22P 排母。

### 3.1 排母引脚定义

```
底板 J1 (左排母, 1×22P, 自上而下)       底板 J2 (右排母, 1×22P, 自上而下)
┌─────────────────────────┐            ┌─────────────────────────┐
│ Pin  J1   → 底板连接     │            │ Pin  J2   → 底板连接     │
├─────────────────────────┤            ├─────────────────────────┤
│  1   GND  ← GND         │            │  1   GND  ← GND         │
│  2   5Vin ← 5V BUS      │            │  2   GND  ← GND         │
│  3   IO14 → TF CLK      │            │  3   IO19 — 悬空(USB)   │
│  4   IO13 → TF CMD      │            │  4   IO20 — 悬空(USB)   │
│  5   IO12 → TF DAT0     │            │  5   IO21 — 悬空(备用)  │
│  6   IO11 → PWR_OFF     │            │  6   IO47 → ADC 电量    │
│  7   IO10 → TF PWR_EN   │            │  7   IO48 — 悬空(备用)  │
│  8   IO9  → I2C SCL     │            │  8   IO45 — 不外接(VDD_SPI)│
│  9   IO46 — 悬空(备用)  │            │  9   IO0  ← SW_BOOT     │
│ 10   IO3  → KEY_VOL_UP  │            │ 10   IO35 — 不外接(PSRAM)│
│ 11   IO8  → I2C SDA     │            │ 11   IO36 — 不外接(PSRAM)│
│ 12   IO18 — 悬空(备用)  │            │ 12   IO37 — 不外接(PSRAM)│
│ 13   IO17 → INMP441 DOUT│            │ 13   IO38 → KEY_MODE    │
│ 14   IO16 → INMP441 WS  │            │ 14   IO39 → MAX SD      │
│ 15   IO15 → INMP441 BCLK│            │ 15   IO40 → MAX GAIN    │
│ 16   IO7  → KEY_VOL_DN  │            │ 16   IO41 → GES INT     │
│ 17   IO6  → MAX DIN     │            │ 17   IO42 → GES RST     │
│ 18   IO5  → MAX WS      │            │ 18   IO2  → KEY_PLAY    │
│ 19   IO4  → MAX BCLK    │            │ 19   IO1  → TF CD       │
│ 20   RST  — 悬空        │            │ 20   IO44 — UART0 RX(预留)│
│ 21   3V3  ← 3.3V_D      │            │ 21   IO43 — UART0 TX(预留)│
│ 22   3V3  ← 3.3V_D      │            │ 22   GND  ← GND         │
└─────────────────────────┘            └─────────────────────────┘

注: 以嘉顺电子科技 ESP-S3 N16R8 实际丝印为准。底板排母丝印标注信号名, 方便查线。
    J1.Pin2(5Vin) 为可选 5V 供电输入，开发板也可直接由 3.3V 引脚供电。
```

> **排母布局建议**：两排排母间距 = 开发板两排排针间距（标准 22.86mm / 900mil），放在底板中央偏上，开发板平躺插在底板上方。

### 3.2 开发板必备外围（底板提供）

| 底板元件 | 连接 | 说明 |
|----------|------|------|
| BOOT 按键 | J2.Pin9(IO0) → SW → GND | 按住上电=下载模式, 底板提供 |
| RST 按键 (可选) | J1.Pin20(RST) → SW → GND | 开发板自带 EN 按键, 底板可再加一个 |

> 开发板自带: USB-C(烧录/串口)、3.3V 稳压、EN/BOOT按键、电源LED。**底板不需要再重复这些**。

## 4. 各外设电路

### 4.1 INMP441 I2S 数字麦克风

```
电源: 3.3V_D
I2S0 (输入): BCLK←J1.Pin15(IO15), WS←J1.Pin14(IO16)
            DOUT→J1.Pin13(IO17) (INMP441→ESP32 数据)
L/R:    GND (左声道), 或 3.3V_D (右声道)
配置:   INMP441 内部 PLL, 无需 MCLK

注: INMP441 为 I2S Slave 模式, WS/BCLK 由 ESP32 I2S0 外设驱动。
    标准配置 16kHz/24bit 或 48kHz/24bit。
```

### 4.2 MAX98357A 功放

```
电源: 5V BUS (经磁珠) → VDD
I2S1: BCLK→J1.Pin19(IO4), WS→J1.Pin18(IO5), DOUT→J1.Pin17(IO6)
控制: SD→J2.Pin14(IO39), GAIN→J2.Pin15(IO40) (+100kΩ↑3.3V_D)
输出: OUT+/OUT- → 喇叭
```

### 4.3 PAJ7620U2 手势

```
电源: 3.3V_D
I2C0: SDA→J1.Pin11(IO8), SCL→J1.Pin8(IO9)
INT: →J2.Pin16(IO41) (低有效)
RST: →J2.Pin17(IO42) (可选)
```

### 4.4 SSD1306 OLED

```
电源: 3.3V_D
I2C0: SDA→J1.Pin11(IO8), SCL→J1.Pin8(IO9)
地址: 0x3C
```

### 4.5 TF 卡座

```
SDMMC 1-bit:
  CLK → J1.Pin3(IO14)  → 33Ω → TF CLK(5)
  CMD → J1.Pin4(IO13)  → TF CMD(3) + 10kΩ↑
  DAT0→ J1.Pin5(IO12)  → TF DAT0(7) + 10kΩ↑
  CD  → J2.Pin19(IO1)  → TF CD(9) + 10kΩ↑

供电: 3.3V_D → P-MOS → TF VDD, Gate←J1.Pin7(IO10)(+10kΩ↑)
      10μF+0.1μF 去耦
```

### 4.6 按键

```
底板提供 4 个功能按键 + 1 个 BOOT 键 + 1 个电源键:

KEY_PLAY  → J2.Pin18(IO2)  → SW → GND
KEY_VOL+  → J1.Pin10(IO3)  → SW → GND
KEY_VOL-  → J1.Pin16(IO7)  → SW → GND
KEY_MODE  → J2.Pin13(IO38) → SW → GND
SW_BOOT   → J2.Pin9(IO0)   → SW → GND  (开发板烧录)
SW_POWER  → IP5306.KEY(5) → SW → GND (电源键)

所有按键需配置 ESP32 内部上拉。
电容去抖 0.1μF 可选。
```

### 4.7 电池电量检测

```
BAT+ → 100kΩ → ADC_MID → 100kΩ → GND
ADC_MID → 0.1μF → GND
ADC_MID → J2.Pin6(IO47) (ADC1_CH6)
```

### 4.8 软关机

```
IP5306.KEY(5) ───┬─── SW_POWER ─── GND
                  │
                  └─── Q_AO3400.Drain
                       Q_AO3400.Source ─── GND
                       Q_AO3400.Gate ─── J1.Pin6(IO11/PWR_OFF) + 10kΩ↓GND

逻辑: 开发板 IO11 拉高 → N-MOS 导通 → KEY 拉低 → IP5306 关机
      开发板拔下 → Gate 10kΩ 下拉 → N-MOS 关断 → 不影响硬件按键
```

### 4.9 I2C 总线上拉

底板放置两个 4.7kΩ 上拉电阻：
```
I2C0_SDA (J1.Pin11/IO8) → 4.7kΩ → 3.3V_D
I2C0_SCL (J1.Pin8/IO9)  → 4.7kΩ → 3.3V_D
```

## 7. 底板 PCB Layout 要点

1. **排母布局**：两排 1×22P 排母间距 = 开发板排针间距。排母下方净空（开发板元件面朝下，避免短路）。
2. **开发板固定**：排母摩擦力固定即可，如需更牢靠可加尼龙柱。
3. **底板 USB-C**：放在板边，只走电源线到 IP5306。D+/D- 不接。
4. **开发板 USB-C**：朝向板外（开发板插在底板后，USB 口朝外），方便插线烧录。
5. **天线净空**：开发板天线区域（通常在 PCB 天线那端）不要被底板铜皮遮挡。底板在对应区域挖空或不开铜。
6. **功率区远离音频区**：IP5306 电感 + SY8088 电感放在底板远离 INMP441 的一侧。
7. **统一地平面**：全数字音频方案，无需模拟/数字地分区，统一 GND 铺铜。
8. **板厚**：1.6mm 标准。双面板即可（2 层），不需要 4 层。
