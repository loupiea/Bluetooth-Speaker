# 蓝牙智能音响方案计划 (单 ESP32-S3 方案)

## 项目概述

蓝牙智能音响，核心功能：蓝牙音频传输、TF 卡播放、WiFi 连接 XiaoZhi 平台做智能对话、手势控制（非视觉方案）、OLED 屏幕显示。**ESP32-S3 开发板直接插底板排母**，底板提供电源 + 全部外设，原型即用。

---

## 硬件形态

```
┌────────────────────────────────────────────┐
│            底板 (Base Board)                │
│                                            │
│   USB-C(充电) → IP5306 → 电池              │
│                  ↓                         │
│              5V → SY8088 → 3.3V_D          │
│                                            │
│   ┌── 排母 J1 ──┐    ┌── 排母 J2 ──┐      │
│   │  1×22P      │    │  1×22P      │      │
│   └─────────────┘    └─────────────┘      │
│          ↑ 开发板插在这里 ↑                │
│          │ 嘉顺 ESP-S3 N16R8 │             │
│          └── 自带 USB-C(烧录) ─┘          │
│                                            │
│   INMP441  MAX98357A  PAJ7620U2  SSD1306  │
│   [数字麦] [功放→喇叭] [手势]    [OLED]   │
│   TF卡座  按键×6  电量LED×4              │
└────────────────────────────────────────────┘
```

**为什么用开发板而不是裸焊模块？**
- 开发板自带 USB-Serial-JTAG、3.3V 稳压、EN/BOOT 按键、天线匹配 → 底板省掉至少 10 个元件
- 排母插拔 → 调试时拔下单独烧录，量产可换模块焊接
- 嘉顺 ESP-S3 N16R8 (~35 元) 比裸模块 N16R8 (~18 元) 贵 17 元，但省下的阻容+插座+烧录口远超此价

## 整体架构

```
┌──────────────────────────────────────────────────────────┐
│  电源管理 (IP5306 → SY8088 + 磁珠滤波)                       │
│  锂电池 3500mAh → 充电/升压5V → 3.3V(数字) + 3.3V(模拟LC滤波)  │
└──────────────────────────────────────────────────────────┘
                              ↓ 供电
┌─────────────────────────────────────────────────────────────┐
│                     ESP32-S3-WROOM-1                         │
│  ┌─────────────────────────────────────────────────────┐    │
│  │  WiFi BGN + BT Classic (A2DP Sink) + BLE 5.0       │    │
│  │  XiaoZhi WebSocket 客户端 + Opus 编解码              │    │
│  │  TF 卡播放 (MP3/FLAC 软解码) + 音源切换              │    │
│  │  FreeRTOS 多任务调度 + 全局状态机                    │    │
│  └─────────────────────────────────────────────────────┘    │
│       │ I2C0          │ I2S0               │ I2S1           │
│  ┌────┴────┐     ┌────┴──────┐      ┌──────┴──────┐        │
│  │PAJ7620U2│     │ INMP441   │      │ MAX98357A   │        │
│  │ 手势    │     │ 数字麦    │      │ 3W 功放     │        │
│  └─────────┘     │ I2S Slave │      └──────┬───────┘        │
│  ┌─────────┐     └────┬──────┘             │                │
│  │SSD1306  │          │                    │                │
│  │OLED     │          ↓                    ↓                │
│  └─────────┘    数字音频入             ┌────────┐          │
│                  (无MCLK)              │ 3W 喇叭 │          │
│                                       └────────┘          │
│                                        └────────┘          │
│   SDMMC 1-bit ─── TF 卡座                                  │
│   ADC ─── 电池电量检测                                      │
│   GPIO ─── 按键 + 功放控制 + 手势INT                        │
│   USB-OTG (GPIO19/20) ─── 烧录+串口调试                    │
└─────────────────────────────────────────────────────────────┘
```

**为什么单芯片就够了？** ESP32-S3 有 2 路 I2S（INMP441 数字麦输入 + MAX98357A 功放输出各一路）、1 路 SDMMC（TF 卡）、2 路 I2C（外设共用一路）、XTENSA LX7 双核 @240MHz + 向量指令，同时处理 WiFi/BT 射频 + Opus 编解码 + TF 卡播放绰绰有余。全数字音频链，双 MCU 通信开销和 PCB 复杂度全部省掉。

## 各板块芯片选型

### 1. 主控 + 无线 — ESP32-S3

| 方案 | WiFi | 蓝牙 | I2S | SDIO | PSRAM | 价格 | 结论 |
|------|------|------|-----|------|-------|------|------|
| **ESP32-S3-WROOM-1-N16R8** | BGN | BT5.0+Classic | 2路 | 1路 | 8MB | ~15 | **选用** |
| ESP32-WROOM-32E | BGN | BT+Classic | 2路 | 1路 | 无 | ~10 | PSRAM 太小，跑 Opus + 解码不够 |
| ESP32-S3-WROOM-1-N8R2 | BGN | BT5.0 | 2路 | 1路 | 2MB | ~12 | PSRAM 偏小 |
| ESP32-C3-WROOM-2 | BGN | BLE 5.0 | 1路 | 无 | 无 | ~7 | 无 Classic BT, 无 SDIO, I2S 不够 |

> **为什么 N16R8 (16MB Flash + 8MB PSRAM)**：8MB PSRAM 同时跑 WiFi 协议栈 + Opus 编解码 + FLAC 缓冲 + OLED 显存 + u8g2 字体缓存，2MB 不够用。

### 2. 音频链路

| 芯片 | 功能 | 接口 | 说明 |
|------|------|------|------|
| **INMP441** | MEMS I2S 数字麦克风 | I2S0 (输入) | I2S Slave，内部 PLL，无需 MCLK |
| **MAX98357A** | 3W I2S Class D 功放 | I2S1 (输出) | 免外围，SD 引脚静音 |
| TPA3116D2 | 50W×2 功放（大功率） | 模拟 | 需前置 DAC，V2 方案 |

### 3. 手势控制 — PAJ7620U2

| 方案 | 手势种类 | 功耗 | 优点 |
|------|----------|------|------|
| **PAJ7620U2** | 9种 | ~5mA 活动 / ~2mA 待机 | 内置识别引擎，I2C 直读 |

#### 手势 → 功能映射

| 手势 | 功能 |
|------|------|
| 挥手（左右） | 切歌（上一首/下一首） |
| 上移 / 下移 | 音量 + / 音量 - |
| 前推 / 后拉 | 暂停/播放 / 静音 |
| 顺时针 / 逆时针 | 唤醒 AI 对话 / 切换到 TF 卡模式 |

### 4. OLED — SSD1306 128×64

| 参数 | 选型 |
|------|------|
| 驱动芯片 | SSD1306（SH1106 备选） |
| 分辨率 | 128×64 单色 |
| 接口 | I2C（0x3C） |
| 驱动库 | u8g2 |

### 5. TF 卡

SDMMC 1-bit 模式（或 SPI 模式），速度足够 FLAC 无损。卡座选 Push-Push 带检测引脚，加 ESD 防护。

### 6. 电源管理

详见下方 7.1-7.16 节（与双芯片方案相同，仅 LDO EN 控制引脚改为 ESP32 GPIO）。

## 烧录与调试 — USB-Serial-JTAG

**不需要 DAP 了**。ESP32-S3 内置 **USB-Serial-JTAG**，GPIO19(USB_D-) + GPIO20(USB_D+) 直连 USB-C 的 D+/D- 即可：

```
ESP32-S3 GPIO19(D-) ──── 27Ω ──── USB-C.A7(D-)
ESP32-S3 GPIO20(D+) ──── 27Ω ──── USB-C.A6(D+)
GND                       ──────── USB-C.GND

功能:
  • USB-Serial-JTAG: esp-idf monitor + openocd 调试
  • USB OTG: 可做 USB 声卡 / U盘模式
  • 固件烧录: idf.py flash (native USB, 无需 CP2102)

注意: USB D+/D- 上的 27Ω 串联电阻用于阻抗匹配 (45Ω+27Ω≈USB 要求的 ~90Ω 差分阻抗的一半)
```

## 软件架构要点

### FreeRTOS 任务划分（ESP32-S3 双核）

| 任务 | 核心 | 优先级 | 说明 |
|------|------|--------|------|
| I2S_DMA_Feed0 | Core 0 | 最高 | I2S0 DMA 中断 → INMP441 录音缓冲区 |
| I2S_DMA_Feed1 | Core 0 | 最高 | I2S1 DMA 中断 → MAX98357A 播放缓冲区 |
| Opus_Decode | Core 0 | 高 | 解码服务器下行的 Opus → PCM |
| Opus_Encode | Core 0 | 高 | 编码麦克风 PCM → Opus 上行 |
| XiaoZhi_WS | Core 1 | 中 | WebSocket 收发 (WiFi) |
| BT_A2DP_Sink | Core 1 | 中 | 蓝牙音频流接收 |
| TF_Player | Core 0 | 中 | TF 卡 MP3/FLAC 软解码 |
| AudioRouter | Core 0 | 中 | 音源混音/切换 (TF/BT/AI → I2S1) |
| UI_Task | Core 1 | 低 | OLED 刷新 + 手势读取 + 按键 |
| Power_Mgr | Core 1 | 最低 | 电量检测 + 低功耗管理 |
| WiFi_Mgr | Core 1 | 低 | WiFi 连接/重连管理 |

> Core 0 处理实时音频（I2S DMA + Opus + 解码），Core 1 处理射频和 UI。利用 ESP32-S3 双核 + 硬件向量指令加速音频。

### 音源优先级

```
TF 卡本地 > 蓝牙 A2DP > WiFi 云端语音
```

### 低功耗策略

| 模式 | WiFi | BT | 音频 | OLED | 电池电流 | 续航(3500mAh) |
|------|------|----|------|------|----------|---------------|
| 深度待机 | OFF | OFF | OFF | OFF | ~3mA | ~50 天 |
| 蓝牙保活 | OFF | Sniff | OFF | OFF | ~8mA | ~18 天 |
| 蓝牙播放 | OFF | A2DP | 中音量 | 定时熄 | ~650mA | ~4.6 小时 |
| AI 对话 | ON | OFF | 低音量 | ON | ~750mA | ~4.0 小时 |

### 关键设计注意点

- **WiFi + BT 共存**：启用 `esp_coex`，A2DP 优先级 > WiFi。
- **I2S0/I2S1 独立时钟**：INMP441 内部 PLL 无需 MCLK，MAX98357A 使用 BCLK 自同步，两路 I2S 独立运行。
- **功放底噪**：无信号时拉低 SD 引脚 → 彻底静音。
- **音源切换防爆音**：静音 → 切换路由 → 50ms 延迟 → 取消静音。

## 电源管理（简化版）

> 双芯片方案的 AP2112K LDO 已省掉。用 **一颗 SY8088 + 磁珠 LC 滤波** 同时产生数字 3.3V 和模拟 3.3V。

### 供电链路

```
电池 3.0-4.2V → IP5306 升压 → 5V BUS
                              │
                      ┌───────┴───────┐
                      ↓               ↓
                  功放 5V_AUDIO    SY8088 DC-DC
                  (经磁珠)       (5V→3.3V_D)
                                      │
                                      ↓
                                 全板 3.3V_D
                         (ESP32/OLED/TF/手势/INMP441)
```

**为什么全数字音频不需要模拟域？** INMP441 输出 I2S 数字信号，MAX98357A 接收 I2S 数字信号。音频链路全程数字，无需 ADC/DAC，无需低噪声模拟电源。SY8088 一颗搞定所有 3.3V ±30mV 纹波对数字电路完全无影响。

### ESP32-S3 电源控制引脚

| 功能 | GPIO | 排母位置 | 说明 |
|------|------|----------|------|
| SY8088 EN | — | — | 直接接 3.3V_D (自举), 5V 上电即启动 |
| 外设断电 P-MOS | GPIO10 | J1.Pin7 | 控制 TF 卡独立供电 |
| N-MOS 软关机 | GPIO11 | J1.Pin6 | 拉低 IP5306 KEY 实现关机 |

### 待机供电策略

```
深度待机 (ESP32 RTC 唤醒):
  INMP441     → I2S BCLK 停 → 自动待机 (~1μA)
  MAX98357A   → SD=低 → 静音+低功耗
  PAJ7620U2   → I2C Sleep (10μA, INT 保持)
  SSD1306     → I2C Display OFF (1μA)
  TF 卡       → SDMMC CLK 停 (100μA), 或 P-MOS 断电 (0μA)
  ESP32       → Deep Sleep, RTC 定时唤醒 (~10μA)
  总电池电流: < 3mA

唤醒源:
  1. PAJ7620U2 INT → ESP32 RTC_IO 唤醒
  2. 按键 (GPIO2/3/7/38) → ESP32 RTC_IO 唤醒
  3. RTC 定时器 → 每 60s 醒来检查电量
```
