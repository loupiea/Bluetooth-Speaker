# 蓝牙智能音响 — 原理图网表 (底板 + ESP32-S3 开发板方案)

## 说明

- `J1.PinX` / `J2.PinX` = 底板排母引脚，对应开发板排针 (1×22P)
- 开发板: 嘉顺电子科技 ESP-S3 N16R8 (2×22P, 2.54mm)
- 每行一条连接。`[必须]` = 不可省略，`[注意]` = Layout 重点关注
